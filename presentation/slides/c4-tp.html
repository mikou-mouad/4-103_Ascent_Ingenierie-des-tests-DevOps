Shift-left et BDD avec Cucumber

1 h · 9h30 – 10h30

tp-04-bdd

Vous allez

  • traduire l'e-mail de Maëlle en exemples chiffrés, à trois amigos
  • écrire les scénarios du tarif résident en Gherkin, avant le code
  • relier les phrases au code Java dans TarifsSteps
  • corriger TarifService, puis publier les scénarios dans Jenkins

C'est réussi quand

tous les scénarios de tarifs.feature passent avec mvn -B test

le rapport Cucumber est lisible par Maëlle

la page du job Jenkins affiche « Scénarios Cucumber »

Énoncé : tp/04-bdd/README.md. Correction : solutions/04-bdd/. La règle du Département : adulte résident 9 €, enfant résident gratuit, vélo au plein tarif (17 €), pas de remise de groupe. Faire jouer l'étape 1 à voix haute, un participant dans chaque rôle. Le rapport local est target/cucumber/rapport.html ; dans Jenkins, il est publié par publishHTML à l'étape « Tests unitaires ».
