TP 07

Déploiement continu avec des tests à chaque étape

1 h · 14h45 – 15h45

tp-07-deploiement

Vous allez

  • écrire les smoke tests de l'application déployée, version comprise
  • prolonger le pipeline : préprod, approbation, production
  • revenir automatiquement à la version d'avant si la production échoue
  • rejouer le vendredi noir : une erreur de configuration propre à la production

C'est réussi quand

après approbation, la production affiche la version 1.0.<build>

avec l'erreur de Tom, le build échoue et la production garde sa version

après correction, la nouvelle version arrive en production

Énoncé : tp/07-deploiement/README.md. Correction : solutions/07-deploiement/. L'incident de l'étape 3 : dans application-prod.properties, maximum-pool-size=2O, avec la lettre O au lieu d'un zéro. Le fichier ne s'applique qu'avec le profil prod : tous les tests passent, la production ne démarre pas (docker logs embarq-prod-app-1), le rollback remet l'ancienne version. Vérifier sur http://localhost:8082/actuator/info. Bonus : un test @ActiveProfiles("prod") aurait vu la coquille dès les tests d'intégration.
