Faire le parallèle avec le public : développeurs, testeurs et QA, ingénieurs DevOps. Chacun se reconnaîtra dans un personnage. Maëlle porte le métier (les règles, les risques, la date), Tom le code, Inès les tests. Le chapitre 4 les réunit autour d'une table : les trois amigos.
