# .gitlab-ci.yml
jenkins:
  stage: jenkins
  tags:
    - embarq # le runner de votre machine
  script:
    - bash embarq/ci/declencher-jenkins.sh

LES ÉTAPES DU JENKINSFILE, AU TP 00

mvn -B compile

Tests unitaires

mvn -B test · rapport junit

Paquet

embarq.jar, archivé

GitLab reste la porte d'entrée, comme dans l'environnement réel des participants ; Jenkins fait le travail. Le job GitLab est exécuté par le GitLab Runner de la machine (exécuteur shell, tag embarq) ; il appelle l'API de Jenkins avec les variables GitLab JENKINS_USER et JENKINS_TOKEN, recopie la console, et échoue si Jenkins ne finit pas en SUCCESS. C'est l'étude de cas du TP 00 : ce que ce pipeline vérifie, ce qu'il ne vérifie pas, combien de temps il prend.
