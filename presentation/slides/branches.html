# une fois, la veille (guide du lab)
git clone \
  https://github.com/mikou-mouad/\
  4-103_Ingenierie-des-tests-DevOps.git \
  ~/iroise

# au début de chaque TP
cd ~/iroise && git fetch
git stash -u
git checkout tp-03-indicateurs
git push gitlab HEAD

Dans chaque branche : l'énoncé (tp/NN-*/) et la correction (solutions/NN-*/), sans rien du TP suivant.

git stash -u met de côté le travail du TP précédent, fichiers non suivis compris : rien n'est perdu. git push gitlab HEAD pousse la nouvelle branche dans le projet gitlab.com du participant : le pipeline GitLab → Jenkins construit le point de départ du TP. Un participant bloqué consulte la correction, ou repart de la branche du TP suivant. La remote gitlab est ajoutée au TP 00.
