JUnit lance les scénarios Cucumber et les tests Selenium

Les scénarios Cucumber sont lancés avec les tests unitaires, par la classe CucumberTest ; les tests Selenium sont des tests JUnit lancés par failsafe dans le profil Maven e2e. Cucumber n'est pas un outil de test d'interface : ici, les scénarios appellent TarifService directement (question 2 du TP 04).
