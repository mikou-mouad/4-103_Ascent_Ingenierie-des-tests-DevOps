TP 00

Le pipeline d'Embarq

1 h · 9h30 – 10h30

tp-00-pipeline

Vous allez

  • démarrer le lab « as code » : Jenkins et Selenium Grid avec Docker Compose
  • créer votre projet embarq sur gitlab.com
  • enregistrer le GitLab Runner et relier GitLab à Jenkins
  • analyser le pipeline d'Embarq, puis le faire échouer

C'est réussi quand

un push sur gitlab.com lance le pipeline Jenkins

le job GitLab recopie la console de Jenkins et prend son résultat

vous avez rempli le tableau des étapes : commande, vérification, durée

Énoncé : tp/00-pipeline/README.md. Correction : solutions/00-pipeline/, dans la branche tp-00-pipeline. Pièges fréquents : projet gitlab.com non public (Jenkins le clone sans mot de passe), variables JENKINS_USER et JENKINS_TOKEN laissées « Protect variable », .bash_logout du compte gitlab-runner (prepare environment: exit status 1). Si le pipeline échoue sur GenerateurReferenceTest : Retry, et on en reparle au TP 03.
