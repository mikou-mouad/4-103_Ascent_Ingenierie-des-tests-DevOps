Quatre types de tests, quatre questions

Unitaires

Une classe seule, sans base ni réseau. Le calcul est-il juste ?

millisecondes

Outil : JUnit 5

TarifServiceTest
ReservationServiceTest

Intégration

Le code avec une vraie base. Les requêtes disent-elles vrai ?

secondes

Outil : Testcontainers

ReservationRepositoryIT
ApiIT

Performance

L'application sous charge. Tient-elle l'ouverture de la saison ?

minutes

Outil : k6

perf/charge.js

End-to-end

Un vrai navigateur, le parcours complet. Un passager peut-il réserver ?

dizaines de secondes

Outil : Selenium

ReservationE2E

Chaque type voit des défauts que les autres ne voient pas. Aucun ne suffit seul.
